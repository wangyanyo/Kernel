## Kernel
微型内核项目，计划有三个阶段：\
**阶段一**：跟着nibblebits的微型内核课程，制作一个可以运行的、功能粗糙但齐全的微型内核；\
**阶段二**：参考书籍《深入Linux内核架构》和Linux内核源码，重构阶段一的微型内核，实现书中所有的功能&特性，验收标准是测试完备，功能和性能符合预期，可以在实际x86_64芯片上运行；\
**阶段三**：进一步修改和扩展微型内核，直到能够直接替换Ubuntu的Linux内核，实际使用不会出现明显的功能和性能问题；
